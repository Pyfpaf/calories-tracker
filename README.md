# Дневник питания и КБЖУ

Автоматический подсчет калорий, расход энергии и отчеты в Telegram.

## Установка

Проект уже установлен в `/root/workspace/calories-tracker/`

## Использование

### Добавление еды
```bash
cd /root/workspace/calories-tracker
python3 tracker.py food "200 г творога, 230 г гречи с говядиной, 3 персика"
```

### Добавление активности
```bash
python3 tracker.py activity "шагов 8500, подтягивания 10, отжимания 30"
```

### Отчет за сегодня
```bash
python3 tracker.py report
```

### Отчет за конкретную дату
```bash
python3 tracker.py report --date 2025-01-30
```

## Автоматические отчеты

Ежедневные отчеты в 7:00 МСК (4:00 UTC):
- Если есть данные — полный отчет за вчера
- Если данных нет — напоминание отправить данные
- В воскресенье — недельный отчет
- В последний день месяца — месячный отчет

## База калорийности

Продукты в `foods.json`. Добавляй новые продукты:
```json
{
  "творог": 110,
  "греча": 150,
  "персик": 40
}
```
Значения — ккал на 100 г.

## Формулы

- **BMR (Миффлин-Сан-Жеора, муж)**: 10 × вес + 6.25 × рост - 5 × возраст + 5
- **Шаги**: 0.5 ккал/кг на 1000 шагов
- **Подтягивания**: 3 ккал/повторение
- **Отжимания**: 2 ккал/повторение

Ваши данные:
- Возраст: 46 лет
- Рост: 187 см
- Вес: 101 кг

Отчеты автоматически запускаются через Hermes cronjob:
- ID: 19811e53236b
- Расписание: 0 4 * * * (7:00 МСК)
